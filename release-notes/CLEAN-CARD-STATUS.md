# Test status

Tested on development hardware:

- Fresh-card installation, owner setup, SSH and Wi-Fi setup.
- Startup display and Home menu.
- Basic and Advanced Wi-Fi.
- General/focused waterfall, including the fixed 2.4 GHz view.
- Device Watch and Security Scan.
- Flipper navigation and app re-entry using the development controller.

No Flipper app is bundled. Real-vehicle OBD2 and 6 GHz still need physical testing. Other hardware and optional external services need broader coverage.

No confirmed outstanding faults are reported for the tested board build. This remains an alpha; compatibility depends on the equipment used.
