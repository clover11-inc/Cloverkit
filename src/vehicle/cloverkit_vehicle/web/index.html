Adapter traffic & keyboard terminal
Local CloverKit and this PC use the same connection. TX is a command written to the adapter; RX is the bytes returned. This is the ELM serial interface, not an unrestricted CAN-bus sniffer.
Read-only OBD terminal
Examples: RPM, 010C, 03, ATI, ATRV. Supported read requests share the adapter owner. Clearing remains in its separate confirmation workflow; write/control commands are not forwarded here.
Access from a PC
Use the authenticated browser through an SSH tunnel, or open the normal menu with sudo bh-panel over SSH. For this terminal in your SSH window, use sudo cloverkit-vehicle terminal. No second USB connection or public port is needed.
