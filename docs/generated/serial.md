# Shared serial console

Status: alpha-hardware-validation-pending
Access: CLI: console

## What it does
Provides one serial owner shared by local/remote terminal clients.

## When to use it
Reach physical console equipment and collaborate.

## Why it is useful
Portable console-server workflow.

## Limits and effects
Account/privilege activation is gated; no remote access is enabled.
