# iperf tools

Status: alpha-hardware-validation-pending
Access: Network > DIAGNOSTICS & CAPTURE

## What it does
Provides server controls and client/interface helpers.

## When to use it
Measure throughput against a controlled peer.

## Why it is useful
Local testing independent of Internet speed servers.

## Limits and effects
Requires a peer; server start opens a listening service.
