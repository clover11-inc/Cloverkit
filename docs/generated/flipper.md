# Flipper control and power

Status: not-included
Access: Flipper companion

## What it does
The board accepts menu controls from a compatible separately supplied Flipper app.

## When to use it
Operate the board while walking without attaching a laptop.

## Why it is useful
Supports local field operation when a compatible companion is available.

## Limits and effects
No companion app or FAP is distributed in this release. Use PC serial or SSH.

## Source
No active implementation included for this deferred integration.
