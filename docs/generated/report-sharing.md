# Remote report viewing

Status: alpha-hardware-validation-pending
Access: Optional; activation deferred

## What it does
Retains an independent restricted scan-report browser.

## When to use it
Let a remote colleague inspect the local scan.

## Why it is useful
Two-person troubleshooting without shared navigation.

## Limits and effects
Candidate includes optional SMTP and local credential fallback; account/policy activation remains gated.
