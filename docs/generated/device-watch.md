# Device Watch

Status: alpha-hardware-validation-pending
Access: Security > Device watch

## What it does
Collects BLE advertisements and Wi-Fi observations with confidence labels.

## When to use it
Discover relevant nearby advertised devices.

## Why it is useful
Selected targets avoid targeting all observations.

## Limits and effects
Identities can be spoofed; foreground targets are capped.
