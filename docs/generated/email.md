# Email setup

Status: alpha-hardware-validation-pending
Access: System > Email setup

## What it does
Guides SMTP setup and shares one sender across access notifications.

## When to use it
Configure optional credential delivery from SSH or serial.

## Why it is useful
Access works without email; failure retains local details.

## Limits and effects
Requires TLS SMTP/app credentials; no test email sent by setup.
