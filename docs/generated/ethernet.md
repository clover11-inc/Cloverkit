# Ethernet link and switch

Status: alpha-hardware-validation-pending
Access: Network > ETHERNET

## What it does
Shows link, counters and observed LLDP/CDP/VLAN/LACP evidence.

## When to use it
Identify a connected switch port and link symptoms.

## Why it is useful
Combines port identity with live link status.

## Limits and effects
Some fields require driver support or switch announcements.
