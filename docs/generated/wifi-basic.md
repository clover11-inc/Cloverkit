# Basic Wi-Fi scan

Status: alpha-hardware-validation-pending
Access: Network > WI-FI

## What it does
Discovers APs, signal, channels and names; creates targets.

## When to use it
Find nearby APs for investigation.

## Why it is useful
Discovery feeds focused follow-up actions.

## Limits and effects
Grouping can be estimated; names may be absent.
