# Saved-capture analysis

Status: alpha-hardware-validation-pending
Access: Network > Packet Captures

## What it does
Analyses DNS, DHCP, TCP retransmission, ARP and broadcast evidence.

## When to use it
Review an incident after capturing it.

## Why it is useful
Turns packets into bounded diagnostic findings.

## Limits and effects
Missing or encrypted traffic can prevent interpretation.
